# issue-10: ダッシュボード (草・進捗・並走者)

## 概要・背景・目的

ログイン後のホーム画面を構築する。yutori の「帰ってくる場所」の中心。

草 (コントリビューショングラフ)、直近の進捗サマリ、並走者リスト、
受信した応援メッセージの有無を表示する。
スマホではこの画面が主役となり、片手で気楽に眺められることを重視する。

## 受け入れ条件

- [ ] apps/web/src/app/(main)/dashboard/page.tsx にダッシュボードが存在する
- [ ] 草 (コントリビューショングラフ) が表示される (ui/components/contribution/grass-graph.tsx)
  - 表示対象: 合格課題のユニーク数、連続学習日数
- [ ] 今週の進捗サマリが表示される (学習日数、クリア課題数、先週との比較)
- [ ] 並走者リストが表示される (ui/components/social/peer-list.tsx)
  - 進度の近い数人を自動ピックアップ
- [ ] 並走者・ランキング表示の ON/OFF が設定から切り替え可能
- [ ] 未読の応援メッセージがある場合、その旨が表示される
- [ ] レスポンシブ対応: スマホでも快適に閲覧・操作できる
- [ ] `make verify` がエラーを発生させない

## 技術的な検討事項

- 草の描画は react-calendar-heatmap または自前の軽量コンポーネント。ライブラリのバンドルサイズを確認して選定する
- 並走者の選定アルゴリズムは core/social/peer-service.ts に置く。「進度の近さ」の定義 (クリア済み課題数の差、直近のアクティブ日の近さなど) は未決事項。MVP ではクリア済み課題数の差が小さいユーザーを数人選ぶシンプルな実装で始める
- ランキングの多軸表示 (最速クリア、最多挑戦、コードの短さなど) は MVP 後の拡張とし、この issue では並走者リストのみ
- 進捗集計は core/learning/progress-service.ts に置く
