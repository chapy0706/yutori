# issue-12: 応援メッセージ

## 概要・背景・目的

並走者に応援メッセージを送る機能を構築する。
3種類の固定文から1つを選んで送る方式とし、自由記述は許可しない。
固定文に限定することで、システムが文面の優しさを保証する。

送ると送り手にもボーナス、受け手はログイン時に受信を楽しめる相互報酬とする。

## 受け入れ条件

- [ ] 並走者リストから1人を選び、応援メッセージを送れる (ui/components/social/encouragement.tsx)
- [ ] 送信時に3種類の固定文から1つを選ぶ UI が表示される
- [ ] 固定文はアプリ定数 (constants/encouragement-presets.ts) で管理される
- [ ] 送信すると encouragement_messages テーブルに記録される
- [ ] 送信者にコインボーナスが付与される
- [ ] 受信者がログインした際に未読メッセージが表示される
- [ ] 既読にすると is_read が更新される
- [ ] `make verify` がエラーを発生させない

## 技術的な検討事項

- 固定文の内容は設計仕様書では「いいペースだね」「一緒にがんばろう」「お疲れさま」程度の温度感を想定している。最終的な文面は実装時に決定する
- メッセージはニックネーム (users.displayName) 付きで表示する。完全匿名ではなく、「他者の存在を意識する」という設計思想に沿う
- 1日に送れるメッセージ数の上限を設けるかどうかは検討事項。MVP ではスパム対策として1日3通程度の上限を設けておくのが無難
